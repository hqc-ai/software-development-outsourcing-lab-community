# Community Scope

## Included
- role-based AI-assisted SDLC reference architecture;
- customer/project isolation pattern;
- deterministic-first engineering pattern;
- governed Tool / Integration Gateway skeleton;
- L0-L5 action classification;
- AI-assisted DevSecOps validation sequence;
- synthetic lab scenarios and evidence patterns.

## Intentionally not included
- real customer repositories or data;
- production CI/CD credentials;
- private infrastructure addresses or secrets;
- proprietary delivery workflows;
- autonomous merge to protected branches;
- autonomous production deployment;
- cross-customer shared memory or artifacts.

The examples are for isolated lab/staging use and must be adapted before any production implementation.
