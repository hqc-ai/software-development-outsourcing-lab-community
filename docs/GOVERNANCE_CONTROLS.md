# Governance Controls

| Control area | Community baseline |
|---|---|
| Agent identity | Role, owner, customer/project assignment, lifecycle state |
| RBAC / Tool access | Least privilege by role and project |
| Project isolation | Separate knowledge, repo, tasks, memory/artifacts, evidence |
| Tool governance | Registered owner/version/roles/scope/credential/approval/log/provenance |
| Model governance | Approved provider/model per project; data-transfer rules recorded |
| Human oversight | Approval at requirement commitment, protected merge/release, production actions |
| Engineering validation | Static validation → tests → diff review → approval → commit/deploy |
| Evidence | Requirement → task → model/prompt → tools → code/test → approval → release artifact |
| Change control | Version prompts, skills, models, coding rules, workflows, tool permissions |
| Incident handling | Record unsafe tool use, hallucinated changes, access boundary failures, deployment failures |
