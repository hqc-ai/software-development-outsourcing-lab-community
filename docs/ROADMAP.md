# Community Roadmap

## Baseline
- role-based PM/BA, Developer, QA, DevOps, Coordinator agents;
- customer/project isolation;
- human approval and evidence traceability.

## Delta 07/08/2026
- deterministic-first engineering routing;
- governed Tool / Integration Gateway;
- common L0-L5 approval model;
- AI-assisted DevSecOps / engineering operations pattern.

## Next community improvements
- synthetic multi-project sample workspace;
- example evidence package for one complete SDLC scenario;
- stronger policy examples for protected branches and deployment gates;
- reproducible validation checklists for PR review, CI/CD triage, and dependency/security review.

Browser automation, voice/STT, cron delivery, and self-hosted/on-prem capabilities remain optional experiments rather than mandatory core architecture.
